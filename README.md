# 영어 친구 — 영어 왕초보용 AI 회화 앱

AI 친구와 영어로 짧게 수다 떨며 듣기 → 따라 말하기 → 읽기 → 쓰기를 연습하는 웹 앱입니다.
React + Vite + TypeScript로 만들었고, AI는 Gemini API(무료 키)를 브라우저에서 바로 부릅니다. 서버는 없습니다.

## 바로 쓰기 (Vercel)

1. 이 코드가 main 브랜치에 있어야 정식 주소가 로그인 없이 열립니다. (다른 브랜치는 무료 플랜에서 미리보기 주소라 Vercel 로그인이 필요합니다.)
2. [vercel.com](https://vercel.com)에서 **Add New → Project** → `grapevine26/vvv` **Import**.
3. Framework Preset이 **Vite**로 자동 선택되는지 확인하고 **Deploy**. Root Directory 등 다른 설정은 그대로 둡니다.
4. 생긴 `https://○○.vercel.app` 주소를 열고, 시작 화면의 **설정**에 Gemini 키를 넣습니다.

Gemini 키는 [Google AI Studio](https://aistudio.google.com/apikey)에서 무료로 받습니다.
**Vercel 환경 변수(Environment Variables)에 키를 넣지 마세요.** 이 앱은 서버가 없어서 쓰이지도 않고, 페이지에 끼워 넣으면 누구나 키를 보게 됩니다.

## 내 컴퓨터에서 돌리기 (Windows)

[Node.js](https://nodejs.org) 22 이상이 필요합니다. PowerShell에서:

```powershell
npm install
npm run dev
```

브라우저에서 `http://localhost:5173`을 엽니다. 코드를 고치면 화면이 자동으로 바뀌어서 다시 켤 필요가 없습니다.

## 테스트

```powershell
npm test                          # 문장 나누기·비교, AI 응답 처리 등 로직 테스트
npx playwright install chromium   # 처음 한 번만
npm run test:e2e                  # 빌드한 앱으로 화면 흐름 테스트 (AI·마이크·스피커는 가짜)
npm run lint                      # 코드 검사
```

## 쓰는 법

| 하는 일 | 방법 |
|---|---|
| 대답하기 | **한** 버튼을 누르고 한국어로 말해도 됩니다. AI가 쉬운 영어 문장으로 바꿔 줍니다. |
| 따라 말하기 | 노란 칸에 문장이 나오면 **EN** 버튼(파랗게 강조됨)을 누르고 따라 말합니다. |
| 대답이 막힐 때 | 질문 아래 "이렇게 대답해도 돼요" 칩을 누르면 들립니다. 그대로 **EN** 버튼으로 말하면 됩니다. |
| 다시 듣기 | 말풍선의 🔊 다시 / 🐢 천천히 |
| 키보드 | 아래 입력칸에 한국어·영어 아무거나 써도 됩니다. |
| 마무리 | **끝내기** → 오늘 문장 듣고 소리 내어 읽기 → 한국어 뜻 보고 영어로 써 보기 → **저장하고 끝내기** |
| 복습 | 저장한 문장은 **내 문장장**에 모이고, 다음 대화에서 AI가 다시 쓰게 합니다. |

## 「AI 원어민 회화 친구 v0.2」 뼈대에서 바꾼 점

| 바꾼 것 | 이유 |
|---|---|
| 질문마다 쉬운 대답 예시 2개 | 왕초보는 영어 문장을 지어낼 수 없어서, 고르고 따라 하게 해야 입이 열린다 |
| 한국어 뜻과 모를 만한 단어를 항상 같이 | 뜻을 모르면 듣기가 그냥 소음이 된다 |
| 글자를 바로 보여 줌 (설정에서 "소리 먼저"로 바꿀 수 있음) | 어른은 글자를 같이 볼 때 소리를 더 잘 잡는다 |
| 마이크 2개 (한 / EN) | 브라우저 음성 인식은 한 번에 한 언어만 알아듣는다 |
| 한국어 신호와 영어를 다른 목소리로 나눠 읽기 | 한 목소리로 읽으면 영어 목소리가 한국어를 읽어 버린다 |
| 틀린 말은 지적 없이 맞는 문장으로 되받기 | 부담 없이 맞는 형태를 계속 듣게 된다 |
| 문법 대신 통째로 쓰는 틀 ("I'm ~", "I want ~") | 문법을 몰라도 바로 쓸 수 있다 |
| 마무리에서 뜻 보고 써 보기 + 다음 대화에서 복습 | 떠올려 보고, 날을 바꿔 다시 쓸 때 기억에 남는다 |
| 모델 이름을 설정에서 바꿀 수 있게 | 모델은 자주 바뀐다. 코드에 박혀 있으면 몇 달 뒤 멈춘다 |

## 폴더 구조

```
src/
  App.tsx              대화 흐름 (시작·주고받기·마무리·저장)
  components/          화면 조각 (말풍선, 마이크 버튼, 설정·마무리·문장장 시트)
  lib/
    prompt.ts          AI에게 주는 지시문 ← 말투·난이도는 여기서 고친다
    gemini.ts          Gemini 호출, 오류 안내, 응답 다듬기
    speech.ts          말하기(음성 합성)·듣기(음성 인식)
    text.ts            한/영 나누기, 문장 비교
    storage.ts         설정·문장장 저장 (브라우저)
    config.ts          기본 설정값
e2e/                   화면 흐름 테스트 (Playwright)
```

## 어디에 무엇이 저장·전송되나

- **이 기기(브라우저)**: 설정, API 키, 내 문장장. 같은 브라우저를 쓰는 사람은 볼 수 있습니다. 기기마다 따로 저장되므로 휴대폰에서는 키를 한 번 더 넣습니다.
- **구글**: 크롬 음성 인식은 소리를 구글 서버에서 글자로 바꿉니다. 대화 내용은 Gemini로 갑니다.
  무료 키로 한 대화는 구글이 서비스 개선에 쓸 수 있으니 **개인정보는 말하지 마세요.**

## 잘 안 될 때

- **"모델을 찾을 수 없어요"** → 설정의 모델 이름을 바꿉니다 (예: `gemini-3.5-flash-lite`, `gemini-3.8-flash`).
- **마이크가 안 됨** → 주소창 왼쪽 아이콘에서 마이크를 허용합니다. 파이어폭스는 음성 인식을 지원하지 않습니다.
- **"무료 사용량을 다 썼거나…"(429)** → 1분쯤 뒤 다시 하거나, 다음 날 씁니다.
- **목소리가 어색함** → 설정에서 목소리를 바꿉니다. 엣지에서는 이름에 "Natural"이 붙은 목소리가 자연스럽습니다.
- **AI 말이 너무 어렵거나 길다** → 설정의 수준을 "완전 처음"으로 낮추거나, `src/lib/prompt.ts`의 규칙을 고칩니다.
